# Notification delivery application: static review demo

This branch contains a small application snapshot for pull request demonstrations.
It handles recipient asset manifests, invoice summaries, export retention, delivery
reporting, report access, and HTML previews.

The files are review data only. Do not run the application, install its dependencies,
or apply Terraform. The GitHub App reviewer runs trusted code from the repository's
default branch and reads these snapshots as data. Demo PRs target this baseline;
do not merge the baseline or intentionally changed application into main.
